## 🚀 **Quick Start**

### Clone & Explore
```bash
git clone https://github.com/Artifact0x0/Artifact0x0.git
cd Artifact0x0

# Explore case studies
cd cases/

# Review detection rules
cd detection-rules/

# Check out automation scripts
cd tools/
```

### Use Detection Rules
```bash
# YARA signatures
yara detection-rules/malware.yar sample_binary

# Sigma rules with tool of choice
sigma -c splunk detection-rules/sigma/ logs/
```
