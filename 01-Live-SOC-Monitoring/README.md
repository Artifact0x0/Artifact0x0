# 🔍 Project 01: Live SOC Alert Monitoring

**Platform:** LetsDefend | **Duration:** 2-3 weeks | **Difficulty:** Beginner

---

## Project Overview

Monitor and triage security alerts in LetsDefend's simulated SOC environment. Learn to classify alerts, gather evidence from logs, and document findings professionally.

This project builds foundational SOC skills: alert classification, log analysis, investigation workflow, and incident documentation.

---

## Learning Objectives

- Master alert triage process (true positive, false positive, benign)
- Analyze logs to identify malicious indicators
- Escalate vs. close alerts based on evidence
- Document investigations professionally
- Recognize common attack patterns

---

## What You'll Do

### Week 1: Foundation
- Complete LetsDefend platform tutorials
- Understand alert classification system
- Triage 15-20 initial alerts
- Build muscle memory for alert workflow

### Week 2: Speed & Patterns
- Process 20-30 more alerts (total: 50+)
- Recognize phishing, brute force, malware patterns
- Reduce triage time from 15 min → 6 min per alert

### Week 3: Deep Dives
- Select 3 best investigations for detailed case studies
- Write comprehensive incident reports
- Capture evidence with screenshots (redacted)
- Document lessons learned

---

## Project Deliverables

### 📋 Triage Log
Complete log of all 50+ alerts investigated with:
- Alert title and severity

### 📊 Case Studies (3)
Detailed write-ups of your best investigations:
- Executive summary

### 📸 Evidence
Redacted screenshots showing:
- Alert dashboard

### 📝 Lessons Learned
Key takeaways and insights from all investigations
