# 🛡️ Project Overview

This repository contains my first hands-on SOC project focused on understanding the alert investigation workflow.

The project documents my practical experience analyzing security alerts, investigating suspicious activity, collecting evidence, identifying Indicators of Compromise (IOCs), and writing investigation reports.

The focus was building a structured approach to security investigations rather than only resolving individual alerts.

---

# 📚 Project Outcomes

Throughout this project I developed practical experience in:

- 🔹 Security Alert Triage
- 🔹 Log Analysis
- 🔹 Incident Investigation
- 🔹 IOC Identification
- 🔹 Evidence Collection
- 🔹 Investigation Documentation
- 🔹 Basic MITRE ATT&CK Mapping
- 🔹 SOC Analyst Workflow
